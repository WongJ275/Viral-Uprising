# Viral-Uprising
Viral Uprising is a 3D game that merges elements of a first-person shooter with the strategic depth of a tower defense game.

<pre>
This is a group project with 2 members.
  
- Individual work: all under Player_script except WeaponSwitching.cs, all under Ingame_Purchase, UIScript.cs
                   animations and visual effects for the player (weapons, skills)
  
- Collaborative work: game planning, game environment design, UI, WeaponSwitching.cs

- The project includes adaptations of third-party materials
</pre>

## How to play
1. Download the zip folder from https://drive.google.com/file/d/1raLAJHZHUYhE03VJ5CuQmCi9N7mEbNkE/view?usp=drive_link
2. Unzip the downloaded folder
3. Launch Viral Uprising.exe
