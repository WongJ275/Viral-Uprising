# Viral-Uprising
Viral Uprising is a 3D game that merges elements of a first-person shooter with the strategic depth of a tower defense game.


## How to play
1. Download the zip folder from https://drive.google.com/file/d/1raLAJHZHUYhE03VJ5CuQmCi9N7mEbNkE/view?usp=drive_link
2. Unzip the downloaded folder
3. Launch Viral Uprising.exe
